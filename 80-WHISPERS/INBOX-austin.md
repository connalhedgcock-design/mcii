# INBOX (AUSTIN) — dump thoughts here

Same rules as Connal's. Type the thought on a new line and stop. Fragments fine, no date, no tags,
no complete sentences. Contradicting an earlier whisper is fine and often the interesting part.

You can also say `whisper: <thought>` to Claude in chat and it gets appended here — verbatim, no
tidying, no discussion. Ids (`w-NNN`) get assigned later; don't bother with them.

! Created 2026-09-01 from Connal's machine, so this file is empty until you use it. Both inboxes
are read together by the `/whispers` synthesis pass, and both sync through git like everything else
in the vault — Connal sees yours, you see his.

! Separate files on purpose: two people appending to the end of one shared file is the most
reliable way to create a merge conflict on exactly the file you both touch most.
